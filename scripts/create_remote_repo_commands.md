# Commands to create and push the repository

## Local Git repository

```bash
cd ros2-child-safety-monitoring
git init
git add .
git commit -m "Initial ROS 2 child safety monitoring prototype"
```

## Push to GitHub

Create an empty GitHub repository first, then run:

```bash
cd ros2-child-safety-monitoring
git init
git add .
git commit -m "Initial ROS 2 child safety monitoring prototype"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/ros2-child-safety-monitoring.git
git push -u origin main
```

## Push to GitLab
